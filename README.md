## Pinned projects

下面列出的是当前 GitHub 主页置顶（pinned）的仓库，按展示顺序给出简短描述：

- [tech-daily](https://github.com/volcanicll/tech-daily) — 每日技术摘要，涵盖加密货币、人工智能和开发者新闻 (JavaScript)。
- [crypto-price-viewer](https://github.com/volcanicll/crypto-price-viewer) — 实时加密货币价格查看器，包含市场数据、供应信息和锁仓明细 (TypeScript)。
- [vscode-text-translator](https://github.com/volcanicll/vscode-text-translator) — 在 VS Code 中将选中内容翻译为目标语言，支持 Microsoft、DeepL、有道和腾讯等 API (TypeScript)。
- [local-group-chat](https://github.com/volcanicll/local-group-chat) — 基于局域网的聊天应用，使用 React + Node.js 实现实时消息与文件分享 (TypeScript)。
- [RcCalendar](https://github.com/volcanicll/RcCalendar) — 日历组件/项目 (TypeScript)。
- [bookmarks-converter](https://github.com/volcanicll/bookmarks-converter) — 书签格式转换工具 (HTML)。
